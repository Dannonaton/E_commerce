# Учебный проект по python

## Описание:
- созданы классы для интернет-магазина
- созданы модуля для тестирование классов
- созданы классы Product и Category
- изменили тип атрибута с продуктами на приватный
- добавили геттер для класса Category для вывода товара
- добавили класс-метод для создания нового товара
- реализовали геттер и сеттер для цены товара
- для классов категории и продуктов реализован метод str
- для класса продукта реализован метод add
- созданы два класса наследников класса Product: "Смартфон" и "Трава газонная"
- класс "Смартфон" расширен атрибутами: производительность, модель, объем встроенной памяти, цвет
- класс "Трава газонная" расширен атрибутами: страна-производитель, срок прорастания, цвет
- создан базовый абстрактный класс с именем BaseProduct 
- реализован класс-миксин для печати в консоль информацию о том, от какого класса и с какими параметрами был создан объект
- реализована обработка исключений, которые могут возникать при обработке товаров и уведомление с их помощью пользователя


## Установка

1. Клонируйте репозиторий:
    ```
    git clone https://github.com/Dannonaton/E_commerce
    ```
2. Установите зависимости:
    ```
   pip install -r requirements.txt
   ```
