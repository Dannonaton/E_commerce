# Учебный проект по python

## Описание:
- созданы классы для интернет-магазина
- созданы модуля для тестирование классов


## Установка

1. Клонируйте репозиторий:
    ```
    git clone https://github.com/Dannonaton/E_commerce
    ```
2. Установите зависимости:
    ```
   pip install -r requirements.txt
   ```
